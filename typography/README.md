# typography

Font families and weights, referencing the Design System.

- [`fonts/`](fonts/): official font files (Chillax, Synonym; OTF and WOFF2) with their licenses. Rules: [`../guidelines/BRAND_RULES.md`](../guidelines/BRAND_RULES.md#typography).
- [`Typography _ Chillax & Synonym.svg`](Typography%20_%20Chillax%20%26%20Synonym.svg), [`Typography _ Backup fonts.svg`](Typography%20_%20Backup%20fonts.svg): original brand charter pages, transcribed in `BRAND_RULES.md` Typography. Do not modify.
- `Chillax_Complete.zip`, `Synonym_Complete.zip`: original font packages as supplied (kept for now; extracted copies in `fonts/`).
- [`Mode 1.tokens.json`](Mode%201.tokens.json): Figma variables export (font families, weights, sizes). See [`../guidelines/BRAND_RULES.md`](../guidelines/BRAND_RULES.md#typography) for rules and open questions.

Link to the Figma/code source of truth instead of duplicating it.
