# brand-examples

Official logo files, plus approved visual references (posters, slides, UI screens, illustrations in context) that AI tools can use as models.

## Official logo files

Supplied by the design team. Never modify, recolor, stretch, redraw or regenerate them. Usage rules: [`../guidelines/BRAND_RULES.md`](../guidelines/BRAND_RULES.md#logo).

| File | Content | Variant |
|---|---|---|
| `Logo-large.svg`, `.pdf`, `.png` (280x191 px) | Wordmark, pictogram and tagline "Smart Energy Management" | Positive |
| `Logo-small.svg`, `.pdf`, `.png` (62x37 px) | Wordmark and pictogram only | Positive |

| `Logo-small-negative.svg` (661x391 px) | Wordmark and pictogram only (same composition as Logo-small, no tagline); white text, orange elements | Negative |

The negative file was supplied as `Logo-negatif.svg` and renamed on import (file content unchanged). There is no negative version of the large logo (with tagline), and none exists; no negative PDF/PNG is supplied yet.

## Third-party logos

Supplied by the design team, in [`third-party-logos/`](third-party-logos/). Noemys is the name of an Energy Pool offer. Authorized backgrounds follow the same rules as the Energy Pool logo (light or white background: light version; plain dark or dark uniform photo: negative version; no orange, strongly colored or mixed light/dark area; procedure in [`BRAND_RULES.md`](../guidelines/BRAND_RULES.md#logo)). Use only these files, never redrawn, recolored or distorted (see `illustrations/STYLE_GUIDE.md` §0.8).

| File | Content | Variant |
|---|---|---|
| `logo-noemys.svg` (285x59 px) | Noemys logo (SVG source: dark grey `#3C3C3C` fills, a gradient mark) | For light backgrounds |
| `logo-noemys-negative.svg` (285x59 px) | Noemys logo (SVG source: white fills, a gradient mark) | For dark backgrounds |

The Noemys logo has no minimum size. Its clear space is `TO BE PROVIDED`; keep it legible and do not assume the Energy Pool value.

## Add an example

1. A designer places the file in a subfolder by type, created when needed (e.g. `posters/`, `slides/`, `ui/`, `illustrations/`). Use lowercase kebab-case names; keep exported originals, never edit them.
2. Add one row to the register with the Figma or source link and the approver.
3. Only designer-approved items belong here. AI-generated drafts do not, until approved and labelled.
