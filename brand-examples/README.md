## Approved examples

**Status: none supplied yet.** Do not add generated or invented examples here, and do not present anything as an approved example unless it appears in the register below.

## Add an example

1. A designer places the file in a subfolder by type, created when needed (e.g. `posters/`, `slides/`, `ui/`, `illustrations/`). Use lowercase kebab-case names; keep exported originals, never edit them.
2. Add one row to the register with the Figma or source link and the approver.
3. Only designer-approved items belong here. AI-generated drafts do not, until approved and labelled.
